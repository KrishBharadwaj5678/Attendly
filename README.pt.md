# 📊 Attendly

Um aplicativo simples e útil que ajuda estudantes a **acompanhar sua porcentagem de frequência** e entender quantas aulas podem **faltar ou precisam frequentar** para manter a frequência mínima exigida.

![AttendlyDemo](https://github.com/KrishBharadwaj5678/Attendly/raw/main/AttendlyDemo.jpeg)

## ✨ Funcionalidades

| Funcionalidade               | Descrição                                              |
| ---------------------------- | ------------------------------------------------------ |
| 📊 Porcentagem de Frequência | Calcula a porcentagem atual de frequência              |
| 🧮 Cálculo Inteligente       | Calcula automaticamente as estatísticas de frequência  |
| ❌ Aulas Perdidas             | Mostra quantas aulas o usuário já perdeu               |
| 💤 Calculadora de Faltas     | Informa quantas aulas podem ser faltadas com segurança |
| 🎯 Meta de Frequência Mínima | Permite definir a frequência mínima exigida            |
| 📱 Interface Simples         | Interface limpa e fácil de usar                        |
