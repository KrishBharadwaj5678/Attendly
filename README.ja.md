# 📊 Attendly

学生が**出席率を管理**し、必要最低出席率を維持するために、**何回授業を欠席できるか、または出席する必要があるか**を把握できる、シンプルで便利なアプリです。

![AttendlyDemo](https://github.com/KrishBharadwaj5678/Attendly/raw/main/AttendlyDemo.jpeg)

## ✨ 機能

| 機能         | 説明                 |
| ---------- | ------------------ |
| 📊 出席率計算   | 現在の出席率を計算します       |
| 🧮 スマート計算  | 出席状況を自動で計算します      |
| ❌ 欠席授業数    | これまでに欠席した授業数を表示します |
| 💤 サボり計算機  | 安全に欠席できる授業数を表示します  |
| 🎯 最低出席率設定 | 必要最低出席率を設定できます     |
| 📱 シンプルUI  | 見やすく使いやすいインターフェース  |

## 🚀 はじめ方

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/Attendly.git
```

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Attendly
```

### 3️⃣ 依存関係をインストール

```bash
flutter pub get
```

### 4️⃣ アプリを実行

```bash
flutter run
```
