# 📊 Attendly

Простое и полезное приложение, которое помогает студентам **отслеживать процент посещаемости** и понимать, сколько занятий они могут **пропустить или должны посетить**, чтобы поддерживать необходимый минимальный уровень посещаемости.

![AttendlyDemo](https://github.com/KrishBharadwaj5678/Attendly/raw/main/AttendlyDemo.jpeg)

## ✨ Возможности

| Функция                          | Описание                                                        |
| -------------------------------- | --------------------------------------------------------------- |
| 📊 Процент посещаемости          | Рассчитывает текущий процент посещаемости                       |
| 🧮 Умный расчёт                  | Автоматически вычисляет статистику посещаемости                 |
| ❌ Пропущенные занятия            | Показывает количество уже пропущенных занятий                   |
| 💤 Калькулятор прогулов          | Показывает, сколько занятий можно безопасно пропустить          |
| 🎯 Минимальная цель посещаемости | Позволяет установить минимальный требуемый процент посещаемости |
| 📱 Простой интерфейс             | Чистый и удобный пользовательский интерфейс                     |

## 🚀 Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/Attendly.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd Attendly
```

### 3️⃣ Установите зависимости

```bash
flutter pub get
```

### 4️⃣ Запустите приложение

```bash
flutter run
```
